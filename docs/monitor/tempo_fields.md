# Tempo Trace Fields

RL-Insight exports completed root spans to Tempo with OpenTelemetry
OTLP/HTTP. This page summarizes the fields emitted by the public tracing APIs
and the Agent Loop protocol so integrators can inspect or publish compatible
data.

## Export format

All trace types use one wire format:

```text
OTLP/HTTP protobuf
POST <otlp-endpoint>/v1/traces
```

In managed-server mode, RL-Insight discovers the endpoint from the RL-Insight
server. In external-OTLP mode, `RL_INSIGHT_OTLP_ENDPOINT` must contain the
complete endpoint, including `/v1/traces`.

Each exported span contains:

| OTLP field | Source |
| --- | --- |
| `name` | Internal event `name`. |
| `startTimeUnixNano` | Internal event `start_time_ns`. |
| `endTimeUnixNano` | Internal event `end_time_ns`. |
| `traceId` | Generated by the OpenTelemetry SDK. |
| `spanId` | Generated by the OpenTelemetry SDK. |
| `parentSpanId` | Empty: RL-Insight exports root spans. |
| `attributes` | Internal event `attributes`. |
| Resource `service.name` | Monitor namespace, defaulting to `trainer`. |

The internal event has this shape before it reaches the monitor hub:

```json
{
  "kind": "trace",
  "name": "rollout",
  "start_time_ns": 1760000000000000000,
  "end_time_ns": 1760000000123000000,
  "attributes": {
    "process_id": "12345",
    "project": "my-project",
    "experiment_name": "my-experiment"
  }
}
```

`kind` is an RL-Insight monitor-event discriminator and is not copied into the
OTLP span attributes.

## Common attributes

Every public tracing API merges these attributes before caller-provided
attributes:

| Attribute | Source | Type |
| --- | --- | --- |
| `process_id` | Emitting process ID. | `str` |
| `project` | `rl_insight.init(project=...)`, when provided. | `str` |
| `experiment_name` | `rl_insight.init(experiment_name=...)`, when provided. | `str` |

Caller attributes are merged last and may override the common values. Attribute
values must be OpenTelemetry scalar values (`str`, `bool`, `int`, `float`) or a
homogeneous sequence of those scalars. Complex values must be JSON encoded by
the caller.

Timestamps are Unix epoch nanoseconds. Empty optional strings should be `""`,
not `None`. When `global_steps` exists, it must remain numeric because the
Agent Loop dashboard uses exact numeric matching.

## `trace_span`: general completed span

`trace_span()` reports one caller-defined completed span:

```python
rl_insight.trace_span(
    name="rollout",
    start_time_ns=start_ns,
    end_time_ns=end_ns,
    attributes={"step": 7, "worker": "w0"},
)
```

| Field | Value |
| --- | --- |
| `name` | Caller-provided span name. |
| `start_time_ns` | Caller-provided start timestamp. |
| `end_time_ns` | Caller-provided end timestamp. |
| `attributes` | Common attributes plus caller-provided attributes. |

`trace_span()` does not add a segment marker or normalize caller fields.

## `trace_op`: operation duration span

`trace_op()` wraps a synchronous or asynchronous callable and reports its
duration:

```python
@rl_insight.trace_op("generate", worker="w0")
async def generate(...):
    ...
```

| Field | Value |
| --- | --- |
| `name` | Explicit name, or the wrapped function's qualified name. |
| `start_time_ns` | Time when the invocation starts. |
| `end_time_ns` | Time when the invocation exits, including exceptions and cancellation. |
| `attributes` | Common attributes, static labels, `extra_labels(first_positional_arg)`, and the segment marker. |

Additional attributes:

| Attribute | Value |
| --- | --- |
| `monitor.trace_segment` | Always `duration`. |

Static labels come from `trace_op(..., key=value)`. Dynamic labels come from
the optional `extra_labels` callback. The marker is written last and cannot be
overridden.

## `trace_state`: state-interval span

`trace_state()` reports a named state interval on a lane. It merges overlapping
intervals with the same name and suppresses a different state while the lane is
occupied:

```python
with rl_insight.trace_state("rollout", state_lane_id="worker-0", batch=1):
    ...
```

| Field | Value |
| --- | --- |
| `name` | The `state_name` argument. |
| `start_time_ns` | Time when the first matching interval opens. |
| `end_time_ns` | Time when the last matching interval closes. |
| `attributes` | Common attributes plus the call's extra labels. |

Additional attributes:

| Attribute | Value |
| --- | --- |
| `monitor.trace_segment` | Always `state_interval`. |
| `state_name` | Human-readable state name and span name. |
| `state_lane_id` | Lane grouping key; defaults to the process ID. |

## Agent Loop identity fields

The three Agent Loop span types share an identity mapping. `state_lane_id` uses:

```text
experiment=<experiment_name>/sample=<sample>/session=<session>/traj=<traj>
```

| Attribute | Requirement | Type |
| --- | --- | --- |
| `project` | Project identity. | `str` |
| `experiment_name` | Experiment identity. | `str` |
| `sample` | Sample identity within the experiment. | `str` |
| `session` | Session identity within the sample. | `str` |
| `traj` | Zero-based trajectory ID; `chain_id - 1` for one-based chain IDs. | `str` or `int` |
| `state_lane_id` | Canonical dashboard lane ID. | `str` |
| `uid` | Optional request UID; use `""` when unavailable. | `str` |
| `global_steps` | Numeric trainer step, or `""` when unavailable. | `int` or `str` |
| `session_id` | Optional framework session ID; use `""` when unavailable. | `str` |

All spans in one session must use the same experiment, sample, session, and
`global_steps`.

## `agent_session`

`session.finish()` emits one `agent_session` root span:

| Attribute | Value |
| --- | --- |
| `monitor.trace_source` | Always `session`. |
| `runner_name` | Task runner name; `""` when unavailable. |
| `status` | One of the status values below. |
| `num_trajectories` | Number of trajectories in the session. |
| `reward_source` | Reward source name; `""` when unavailable. |
| `finished` | Whether the session finished; may be `""`. |

The span also contains every Agent Loop identity field.

## `agent_task`

A task runner emits one `agent_task` root span per task:

| Attribute | Value |
| --- | --- |
| `monitor.trace_source` | Always `task`. |
| `task_name` | Task name. |
| `image_ref` | Task image reference; `""` when unavailable. |
| `prompt_hash` | Hash of the prompt. |
| `status` | One of the status values below. |
| `reward` | Final scalar reward. |
| `accuracy` | Task accuracy when available. |
| `finished` | Whether the task finished. |
| `reward_posted` | Whether reward posting succeeded. |
| `error` | Error text; `""` when there is no error. |

The span also contains every Agent Loop identity field.

## `gateway_generation`

A model gateway emits one `gateway_generation` root span per generation:

| Attribute | Value |
| --- | --- |
| `monitor.trace_source` | Always `gateway`. |
| `chain_id` | Framework chain ID, normally one-based. |
| `turn` | Zero-based model turn number. |
| `type` | Generation type defined by the gateway. |
| `tools` | Parallel list of tool names. |
| `tool_args` | Parallel list of JSON-encoded tool arguments. |
| `reasoning` | Model text before `</think>`. |
| `content` | Model answer after `</think>`. |
| `prompt_tokens` | Prompt token count. |
| `completion_tokens` | Completion token count. |
| `finish_reason` | Model finish reason. |
| `status` | One of the status values below. |
| `error` | Error text; `""` when there is no error. |

The span also contains every Agent Loop identity field. `tools` and
`tool_args` must have the same length.

## Status values

Agent Loop spans use:

```text
success
failure
empty
capacity_exhausted
error
```

Publish failed operations as well as successful ones. Timestamps must remain
monotonic within a span.

## Field summary

| API or span | Span name | Distinguishing attributes |
| --- | --- | --- |
| `trace_span()` | Caller-defined | Caller-defined only. |
| `trace_op()` | Explicit or function name | `monitor.trace_segment="duration"`. |
| `trace_state()` | `state_name` | `monitor.trace_segment="state_interval"`, `state_name`, `state_lane_id`. |
| Agent session | `agent_session` | `monitor.trace_source="session"`, `runner_name`, `status`, `num_trajectories`, `reward_source`, `finished`. |
| Agent task | `agent_task` | `monitor.trace_source="task"`, `task_name`, `image_ref`, `prompt_hash`, `status`, `reward`, `accuracy`, `finished`, `reward_posted`, `error`. |
| Model generation | `gateway_generation` | `monitor.trace_source="gateway"`, `chain_id`, `turn`, `type`, `tools`, `tool_args`, `reasoning`, `content`, token counts, `finish_reason`, `status`, `error`. |
